# 国际化（i18n）

## 内置语言

组件库内置 `zh-CN`（默认）和 `en-US` 两套文案，覆盖弹层确认/取消、空态、加载态、日期与键盘等所有组件内置文案。切换语言不需要安装任何额外依赖。

```ts
import { setLocale, useLocale } from '@mosquito/ui'

setLocale('en-US')
useLocale().t('common.confirm') // 'Confirm'
```

> 根入口是否导出 locale API 取决于你使用的构建产物；若根入口未导出，可从 `@mosquito/ui/composables` 引入 `useLocale`，或从内部模块 `@mosquito/ui/locale` 引入 `setLocale` / `t` / `addMessages`。

## 三种切换方式

### 1. 直接调用 setLocale

```ts
import { setLocale } from '@mosquito/ui/locale'

setLocale('en-US')
```

语言状态是模块级单例：`setLocale` 之后，所有已挂载组件立即重新渲染；组件卸载不会把语言回滚。

### 2. 使用 MqConfigProvider

```vue
<script setup lang="ts">
import { ref } from 'vue'

const lang = ref('zh-CN')
</script>

<template>
  <mq-config-provider :locale="lang">
    <mq-dialog v-model="visible" />
  </mq-config-provider>
</template>
```

`locale` prop 变化时会调用 `setLocale`。不传时不会修改当前语言；卸载时也不会回滚。

### 3. 在逻辑里使用 useLocale

```ts
import { useLocale } from '@mosquito/ui/composables'

const { locale, t, setLocale, addMessages } = useLocale()

locale.value // 当前语言
t('common.loading', {}) // 任意位置取文案
```

## 自定义语言包

`addMessages` 会按叶子键深合并，未提供的键继续走内置文案（缺失时回退 `zh-CN`）。

```ts
import { addMessages, setLocale } from '@mosquito/ui/locale'

// 覆盖部分内置文案
addMessages('en-US', {
  'common.confirm': 'OK',
  'common.cancel': 'Dismiss',
  'common.total': '{{total}} records',
})

// 也可以写成嵌套对象，会自动摊平成 a.b.c
addMessages('ja-JP', {
  common: {
    confirm: '確認',
    cancel: 'キャンセル',
  },
  calendar: {
    monthTitle: '{{year}}年{{month}}月',
  },
})

setLocale('ja-JP')
```

### 一套新语言的完整示例

```ts
import { addMessages, setLocale } from '@mosquito/ui/locale'

addMessages('fr-FR', {
  'common.cancel': 'Annuler',
  'common.confirm': 'Confirmer',
  'common.close': 'Fermer',
  'common.search': 'Rechercher',
  'common.noData': 'Aucune donnée',
  'common.loading': 'Chargement',
  'calendar.prevMonth': 'Mois précédent',
  'calendar.nextMonth': 'Mois suivant',
})
setLocale('fr-FR')
```

未翻译的 key 会回退到中文，可以逐步补全。可用 key 清单见 [locale 组件文档](../component/locale.md)。

## 插值与查找顺序

```ts
t('calendar.monthTitle', { year: 2026, month: 3 }) // '2026年3月' 或 '2026/3'
t('common.total', { total: 12 }) // '共 12 条'
t('unknown.key') // 'unknown.key'
```

查找顺序：当前语言 → `zh-CN` → key 本身。`setLocale(locale, messages)` 可以在切换语言的同时合并一份文案，`addMessages` 则只合并、不切换语言。

## 组件文案覆盖规则

带文案 props 的组件（如 `MqDialog` 的 `confirmText`、`MqSearch` 的 `placeholder`、`MqCalendar` 的 `confirmText`）优先使用调用方传入的值；未传时使用 `t(...)` 的当前语言文案。因此切换语言后：

- 未显式传文案的组件自动更新；
- 显式传文案的组件保持调用方的值；
- 事件 payload 与原有 API 完全不变。
